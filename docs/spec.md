# 두벌식 조합 규칙 — homi spec

`HangulCore` 가 따르는 규칙. 이 문서의 예는 `Tests/HangulCoreTests` 가 그대로 고정한다 — 둘이 어긋나면 둘 다 고친다.
Apple 두벌식과 다른 곳은 ⚠️ 로 표시한다.

표기: `ㄱㅏ｜ㄴ` — `｜` 앞은 확정된 글자, 뒤는 조합 중인 글자(marked text).

## 자판

| key | 자모 | Shift |
|---|---|---|
| Q W E R T | ㅂ ㅈ ㄷ ㄱ ㅅ | ㅃ ㅉ ㄸ ㄲ ㅆ |
| Y U I O P | ㅛ ㅕ ㅑ ㅐ ㅔ | ㅛ ㅕ ㅑ ㅒ ㅖ |
| A S D F G | ㅁ ㄴ ㅇ ㄹ ㅎ | 같다 |
| H J K L | ㅗ ㅓ ㅏ ㅣ | 같다 |
| Z X C V | ㅋ ㅌ ㅊ ㅍ | 같다 |
| B N M | ㅠ ㅜ ㅡ | 같다 |

- key 는 물리 위치(`keyCode`)로 읽는다. 그 아래 깔린 keyboard layout 이 무엇이든 같다. Caps Lock 은 무시한다.
- Apple 의 `com.apple.keylayout.2SetHangul` 과 같은 표다 — test 가 system 의 layout 과 대조한다.
- 이 표에 없는 key(숫자·문장부호·`` ` ``·Space…)는 자모가 아니다. 조합을 확정하고 key 는 app 으로 넘긴다 (`Session` 의 일).

## 음절의 재료

- 초성 19: ㄱ ㄲ ㄴ ㄷ ㄸ ㄹ ㅁ ㅂ ㅃ ㅅ ㅆ ㅇ ㅈ ㅉ ㅊ ㅋ ㅌ ㅍ ㅎ
- 겹모음 — key 둘: ㅗ+ㅏ=ㅘ ㅗ+ㅐ=ㅙ ㅗ+ㅣ=ㅚ ㅜ+ㅓ=ㅝ ㅜ+ㅔ=ㅞ ㅜ+ㅣ=ㅟ ㅡ+ㅣ=ㅢ
- 받침이 될 수 없는 자음: ㄸ ㅃ ㅉ
- 겹받침 — key 둘: ㄱ+ㅅ=ㄳ ㄴ+ㅈ=ㄵ ㄴ+ㅎ=ㄶ ㄹ+ㄱ=ㄺ ㄹ+ㅁ=ㄻ ㄹ+ㅂ=ㄼ ㄹ+ㅅ=ㄽ ㄹ+ㅌ=ㄾ ㄹ+ㅍ=ㄿ ㄹ+ㅎ=ㅀ ㅂ+ㅅ=ㅄ
- ㄲ·ㅆ 받침은 Shift 로 친 key 하나다 (ㄱ+ㄱ 이 아니다).

## 조합

조합 중인 음절은 **그 음절에 친 key 들**로 기억한다. 보이는 글자는 그 key 들로부터 계산한다.
그래서 Backspace 는 마지막 key 를 빼는 것이고, 도깨비불은 마지막 key 를 다음 음절로 옮기는 것이다.

| 지금 | 친 것 | 결과 | 예 |
|---|---|---|---|
| 없음 | 자음·모음 | 새 음절 | ㄱ → `｜ㄱ` |
| 초성만 | 모음 | 초성+중성 | ㄱ ㅏ → `｜가` |
| 초성만 | 자음 | 확정하고 새 음절. ⚠️ 같은 자음도 합치지 않는다 | ㄱ ㄱ → `ㄱ｜ㄱ` · ㄱ ㅅ → `ㄱ｜ㅅ` |
| 중성만 (모음으로 시작) | 모음 | 겹모음이 되면 합치고, 아니면 확정 | ㅗ ㅏ → `｜ㅘ` · ㅏ ㅏ → `ㅏ｜ㅏ` |
| 중성만 | 자음 | 확정하고 새 음절 | ㅏ ㄱ → `ㅏ｜ㄱ` |
| 초성+중성 | 모음 | 겹모음이 되면 합치고, 아니면 확정 | 고 ㅏ → `｜과` · 가 ㅏ → `가｜ㅏ` |
| 초성+중성 | 자음 | 받침이 될 수 있으면 받침, 아니면 확정 | 가 ㄱ → `｜각` · 가 ㄸ → `가｜ㄸ` |
| 받침 하나 | 자음 | 겹받침이 되면 합치고, 아니면 확정 | 갈 ㄱ → `｜갉` · 각 ㄴ → `각｜ㄴ` |
| 받침 하나 | 모음 | **도깨비불** — 받침이 다음 음절의 초성이 된다 | 각 ㅏ → `가｜가` · 벘 ㅡ → `버｜쓰` |
| 겹받침 | 자음 | 확정하고 새 음절 | 갉 ㄱ → `갉｜ㄱ` |
| 겹받침 | 모음 | **도깨비불** — 뒤 key 만 넘어간다 | 맑 ㅗ → `말｜고` · 갃 ㅏ → `각｜사` |

## Backspace

- 조합 중이면 **마지막 key 하나를 되돌린다** (자소 단위): 닭 → 달 → 다 → ㄷ → 없음.
  겹모음·겹받침은 key 둘이라 하나씩 풀린다: 궤 → 구, 갉 → 갈. Shift 로 친 ㅆ 은 key 하나라 통째로: 갔 → 가.
- 조합 중인 것이 없으면 Backspace 는 app 으로 넘어간다 — 확정된 글자는 app 이 지운다.
- 도깨비불로 넘어간 뒤의 앞 음절은 이미 확정이다: 달기 → ⌫ → `달｜ㄱ`.

## 확정

자모가 아닌 key, 수식키 조합(⌘·⌃·⌥), 모드 전환, focus 이동은 조합 중인 음절을 그대로 확정한다 — `Session` 이 `flush` 를 부른다.

## 출력 문자

- 음절: 완성형 (U+AC00–D7A3) = `0xAC00 + (초성 × 21 + 중성) × 28 + 종성`
- 낱자모(초성만, 중성만): 호환 자모 (U+3131–3163). Apple 과 같다 (probe 로 확인).
